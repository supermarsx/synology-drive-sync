Updates

GitHub Releases contains published release assets. Use the compatible release selector to select the exact SPK for the NAS model, DSM version, and CPU architecture. Verify the asset checksum, then upgrade with Package Center > Manual Install.

Package lifecycle scripts retain configuration and protected secrets during an upgrade. The AppWindow does not fetch or install updates and does not configure Package Source discovery.

The Rust list shows every direct dependency selected by the root Cargo.toml, with its exact version resolved by the frozen Cargo.lock, including target-specific packages. The DSM UI list mirrors the exact versions in package.json and the pinned package manager. THIRD_PARTY_LICENSES.html contains the complete transitive Rust release-dependency license inventory. Notices for runtime code embedded in the AppWindow bundle ship separately as DSM_UI_THIRD_PARTY_LICENSES.txt. Vue is supplied by DSM and is not bundled; other pnpm packages whose code is not named in that notice are used only during the build.
