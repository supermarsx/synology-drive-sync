# Security policy

Please report suspected vulnerabilities privately through GitHub's **Security > Report a vulnerability** flow. Do not include DSM passwords, OTPs, session IDs, SynoTokens, private hostnames, or file contents in a public issue.

Only the latest release and the current `main` branch receive security fixes.

This tool can delete remote data only when `--delete` is explicitly enabled. Reproduce destructive issues against a disposable destination and redact all credentials and paths from diagnostics.
